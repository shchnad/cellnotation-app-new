# How to Use the Music Composer App

## Create Measures

Start by creating measures: tap the 'Add Measures' icon, or the 'Add Measures' button in the middle of the screen.

Set the scale and time signature while creating them. You can change the scale and time signature later if needed.

## Set Hand and Duration

Before creating notes, set the hand by tapping the 'Hand Set' icon, and the duration by tapping the 'Note Duration' icon.

## Create, Move, Edit Notes

To add a note, tap the grid on the correct row (pitch) and beat (column).

To edit or delete a note, tap it to open the note-editing dialog.

To move a note, drag it.

To copy a note, press and hold it. The 'Paste Mode' icon highlights, and you can now paste the copy by tapping the grid. To stop pasting, tap the 'Paste Mode' icon again to turn it off.

## Edit Tempo, Scale, Time Signature

To edit the tempo, scale, or time signature, tap its label on the grid. You can also edit it by double-tapping the measure to open the beat-and-measure dialog. Choose 'Set Tempo', 'Set Scale', 'Insert Beat', 'Duplicate Beat', or 'Delete Beat'.

## Add Finger Number, Articulation, Ornament, Playing Technique

To add a finger number, articulation, ornament, or playing technique, tap a note to open the note-editing dialog. Choose 'Finger', 'Articulation', 'Ornament', or 'Playing Technique' to open the matching picker. You can delete the value using the same dialog.

## Add Glissando

To add a glissando, tap a note to open the note-editing dialog. Choose 'Glissando', pick a direction, then tap the row (pitch) where the glissando should end. You can delete the glissando using the same dialog.

## Add Grace Notes

To add grace notes, tap a note to open the note-editing dialog. Choose 'Grace Notes', pick a type and then choose to add before the note or after, then, while the 'Grace Notes' icon is highlighted, tap the grid on the correct rows (pitches). To stop adding, tap this icon to turn Grace Notes Mode off.

Appoggiatura is always half of the note's own length, and only one fits at a time.

Acciaccatura Long (sixteenth), Medium (thirty-second), Short (sixty-fourth) are always a fixed length, however long the note is.

## Mark Legato

To mark legato, tap the 'Legato Mode' icon; it highlights to show that Legato Mode is on. Now tapping a note marks it to be played legato. Tap the highlighted 'Legato Mode' icon again to turn it off.

## Add Dynamic, Pedal

To add or edit a dynamic marking or pedal, double-tap the grid on the correct beat (column) to open the beat-and-measure dialog. Choose 'Set Dynamic', 'Set Dynamic Change', or 'Set Pedal'.

## Add Fermata

To add a fermata, double-tap the grid on the correct beat (column) to open the beat-and-measure dialog. Choose 'Set Fermata', then pick or enter how many beats this beat should last. To delete the fermata, use the same dialog.

## Playback

To scroll the screen, tap the 'Play/Pause' icon. The scrolling speed depends on the tempo, so you can change the scrolling speed by changing the tempo. Scrolling can be paused by tapping the icon again, or simply by tapping the grid. Tapping the grid again resumes scrolling. Use the 'Scroll to Start' icon to jump to the beginning, and the 'Go to Measure' icon to jump to a chosen measure.

## Lock Mode

To prevent editing, tap the 'Lock Mode' icon; it highlights to show it's on. Tap it again to turn it off and allow editing. It turns on automatically during playback or while the scale is raised or lowered.

## Easy Read Mode

While Easy Read Mode is on, notes are shown in whichever way is easiest to read. This mainly concerns notes with accidentals. Easy Read Mode turns on automatically during playback or while the scale is raised or lowered.

## Rotate Mode

Tap the 'Rotate Mode' icon to rotate labels 90°, useful to see the cellnotation as piano roll. This also turns Lock Mode and Easy Read Mode on. Tap Rotate Mode off to turn labels back.

## Scale Up/Down/Reset

Scale Up and Scale Down shift the whole piece by a semitone. Tapping the same icon repeatedly can raise or lower the piece by up to 12 semitones.

Reset Scale returns it to its original pitch.

## Accidentals Mode

Tap the 'Accidentals Mode' icon to see every note with an accidental — in other words, every note that doesn't belong to the scale.

These notes turn red. Tap this icon again to turn Accidentals Mode off.

## No Fingers Mode

Tap the 'No Fingers Mode' icon to hide fingering numbers. Tap it again to turn this mode off.

## Dark Mode

Tap the 'Dark Mode' icon to switch the grid's background to black, which can make the grid easier to see in low light. Tap it again to switch back to the normal background.

## Reference Columns

Tapping the 'Reference Columns' icon shows two extra columns: one with each note's letter name (C4, A5#), and one with its transcription code used for Export and Import (0, 6/7+).

## Export and Import

Export shows a chosen range of measures as text in the line-position transcription notation, which can be copied to the clipboard. Import lets you paste or type that same notation to add measures and notes; its own 'Help' button explains the full notation.
